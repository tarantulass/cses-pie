# CSES Problem Set Journey 🚀

A collection of my solutions to the **CSES Problem Set**, written in **C++**, documenting the slow but hopefully steady journey of becoming better at **problem solving, algorithms, and competitive programming**.

This repository is not just about accepted submissions — it is also about understanding *why* an algorithm works, debugging strange edge cases, and occasionally questioning life decisions after staring at one bug for hours.

---

## Why this repository?

The goal is simple:

- Improve problem-solving skills
- Build stronger intuition for algorithms and data structures
- Learn to think in terms of **optimization**, not brute force
- Turn *"I vaguely understand this"* into *"I can implement this confidently"*

And maybe stop getting TLE on 4 hidden test cases.
